# Third-party dependencies and supplied material

This application uses installed packages rather than embedding copied framework source. Retain the upstream license files distributed with those packages. The exact tested Python versions are in `backend/requirements.lock.txt`; npm resolution and license fields are in `frontend/package-lock.json`. Run `backend/.venv/Scripts/python.exe scripts/dependency_licenses.py` (Unix: `backend/.venv/bin/python`) to export license metadata for review.

Principal dependencies: FastAPI, Pydantic, SQLAlchemy, Alembic, Next.js, React, Tailwind CSS, Lucide, pytest, httpx, Uvicorn, psycopg, itsdangerous, PostgreSQL, Argon2-CFFI, email-validator, python-multipart and pypdf. Their upstream distribution license files remain authoritative, including psycopg and transitive binary/runtime notices. A machine-readable inventory is in `submission/evidence/dependency-licenses.json`; metadata is not a substitute for a distribution/legal review. No commercial SDK, payment integration source, stock photograph, copied insurance contract or external font is embedded. Frankfurter usage/source links are documented in docs/14_MVP_APIS_AND_PROVENANCE.md.

The original proposal DOCX and implementation kit were supplied by the user and are preserved as reference material. The fictional policy and seed data remain clearly labelled synthetic; no official insurer terms are copied into the app. No additional license grant over the user's supplied reference documents is asserted.
